# Badminton Footwork Lab

A very simple Streamlit web app for six-corner badminton footwork training.

## Features

- Random six-corner footwork calls
- Adjustable time between calls
- Adjustable session length
- Front-court, rear-court, side-only, or full random mode
- Rep counter
- Basic session summary chart

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy with Streamlit Community Cloud

1. Create a GitHub repository.
2. Upload `app.py` and `requirements.txt`.
3. Go to Streamlit Community Cloud.
4. Connect your GitHub account.
5. Select the repository.
6. Set main file path to `app.py`.
7. Deploy.
